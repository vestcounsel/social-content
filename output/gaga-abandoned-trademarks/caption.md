# Caption — Lady Gaga's Abandoned Trademarks (Instagram / LinkedIn)

Even Lady Gaga's portfolio includes 42 abandoned trademark applications — BAD ROMANCE and EAU DE GAGA among them. Here is what founders often get wrong: abandoned describes the application, not the brand.

Every one of those 42 was an intent-to-use filing — a placeholder that only matures into a registration once commercial use is proven. Deadlines pass, plans change, filings get replaced by sharper ones. The status line never tells you which.

And an abandoned application does not make a name available: common-law rights, related live registrations, and continued marketplace use can all survive it.

Takeaway: if you file, calendar every deadline. If you are searching, treat an abandoned application as the start of a question — never as clearance.
